# 移动端整理方案

产品定位：两个人各自记录生活与目标、共同规划事情，并在规则确定后通过积分兑换奖励。

## 反馈与调整

1. 入口：支持账号注册、登录和邀请另一位成员，已有账号与原空间保留。新空间的数据应相互隔离。
2. 身份：同一账号在不同设备显示同一人的昵称和头像；自己只能在界面上修改自己的资料。
3. 积分：每人可设置自己目标的单次打卡得分；记录关联目标后由服务端发分。奖励或愿望由兑换者使用自己的积分支付，并校验余额。
4. 流程：手机底部是今天、一起、积分、回看；设置从今天右上角进入。今天可以管理目标并记一笔；一起包含共同计划和创意。
5. 目标：原关键词并未驱动计数，移除误导性提示；记一笔时可选目标，根据本周已关联记录计算进度。结束目标需明确确认，不把结束目标当打卡。
6. 同步：基于共同的旧版本合并不同数据的修改，同一内容冲突时停止并保留本地副本；旧版本不存在时不自动覆盖。

## 尚未完成

- 私人记录和个人目标已在本机加入服务端筛选；旧记录默认继续共享。仍需完成旧数据迁移、权限安全审计和真实环境验证。
- 当前只支持自己设置自己的目标；由一人给另一人设置目标、共同兑换分摊和更复杂的积分规则可后续讨论。
- 注册、邀请、同步与迁移需继续做安全评估、移动设备实测和备份恢复验证，不能仅凭本地测试投入正式使用。
- 不同设备的实时推送、真正的细粒度操作日志、长期离线与复杂冲突处理仍未实现。
- Android WebView 测试包已有自动构建脚本，已在联想平板安装启动；它加载线上网站，尚不包含本机未部署的改动，备份导出暂需用手机浏览器。正式版需要安全的发布签名与更全面的手机测试。
