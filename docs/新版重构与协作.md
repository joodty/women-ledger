# 新版重构与协作

本次目标：保留现有移动端风格与已有账本数据，重构全部前端与后端模块；前端使用 Vue 3、TypeScript、Vite，GitHub Actions 构建并发布可运行产物，平板不执行 npm 安装和前端构建。

## 实施边界

- `frontend/src/features` 按账号、记录、约定、积分、故事、回看、设置组织真实 Vue 组件；不继续加载旧 `original.js`。
- 后端保持 Node.js 与 SQLite；账号和数据 ID 保留，旧数据库通过可重复迁移建立逐项数据索引及操作去重表。
- 新前端发送明确操作，不上传整份账本。服务端负责权限、字段校验、积分计算和事务。
- 未提交操作按稳定账号持久保存；重启后可找回。真实同字段冲突保留双方版本，不删除本机草稿。
- 原安卓通知、语音、更新能力保留；发布前必须测试双账号、数据权限、冲突、离线恢复和数据库副本迁移。

## 发布要求

后续章节将在实现与验证完成后补充精确命令、目录职责、API 契约、兼容迁移、GitHub 发版和回滚步骤。未完成测试不得将开发中的重构发布到生产。
