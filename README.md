# 我们：双人生活记录

移动端优先的双人空间：记录、约定打卡、个人与共同积分、愿望兑换、故事接龙和回看。沿用原来的低饱和配色与卡片设计。

当前为 v2 模块化版本：Vue 3 + TypeScript + Pinia + Vite 前端，按领域拆分的 Node.js 24 后端与 SQLite。前端提交独立操作，服务端校验权限、并发版本、积分和重复请求；未提交内容按账号保存在本机。

**维护者和协作 AI 开始前请读 [开发发布手册](docs/开发发布手册.md) 与 [AGENTS.md](AGENTS.md)。** 手册涵盖模块职责、API、数据兼容、GitHub 构建、安卓打包、自动部署和回退。

## 本机开发

要求 Node.js 24。使用独立测试数据，不连接生产账本。

```sh
npm ci
npx playwright install chromium
npm test
node server.cjs
```

浏览器打开 http://127.0.0.1:18763。开发热更新另开终端执行 `npm run dev`。测试会先构建，并使用独立临时数据库。生产启动目录不需要安装前端依赖。

## 发布

代码合并到 main 后创建正式 GitHub Release。GitHub Actions 构建并测试，将可运行压缩包和校验文件附加到发布版本；平板每五分钟检查并备份、验证、部署。普通 push 不上线。

安卓代码变化时需使用原签名另外构建 APK，并把签名安装包附加到同一个 Release。平板未取得必需 APK 前不会激活对应网站版本。应用更新仍需要安卓系统的安装确认。

账号、SQLite 数据、历史快照和积分通过新增表兼容迁移保留。`原始页面.html` 只作为设计参考，不参与构建或运行。数据库、凭证、私钥、签名文件、真实用户截图不得提交仓库。
